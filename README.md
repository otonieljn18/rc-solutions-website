# RC Solutions — website

Marketing site for **RC Solutions** (RC Soluciones RPA): nearshore automation and engineering teams in Santo Domingo, Dominican Republic, serving US companies.

- Plain HTML, CSS and JavaScript — no build step.
- English / Spanish toggle (Spanish copy lives in `main.js`; you can also link with `?lang=es`).
- Brand assets are in `assets/` (logo, white logo, founder photos).

## Edit

- Page content: `index.html` (English) and the `ES` object in `main.js` (Spanish).
- Colors and fonts: the variables at the top of `styles.css`.

## Run locally

Open `index.html` through any static web server, for example the VS Code "Live Server" extension.

## Contact form

The form opens the visitor's email app addressed to arincon@ and orincon@rcsolucionesrpa.com. To receive submissions directly, connect a form service (for example Formspree) in `main.js`.
